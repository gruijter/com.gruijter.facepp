Используйте снимки с камеры, подключённой к Homey, и позвольте Face++ выполнить распознавание лиц на основе ИИ. Для каждого обнаруженного лица будет запущен flow. Homey автоматически попытается сопоставить лица с набором известных лиц, которые вы можете загрузить самостоятельно. Приложение также оценит пол, возраст, эмоции и то, носит ли человек (солнцезащитные) очки или маску.

Варианты использования: обнаружение присутствия, безопасность, контроль доступа по лицу, развлечение

Для получения дополнительной информации посетите форум.
