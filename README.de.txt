Verwenden Sie Schnappschüsse einer mit Homey verbundenen Kamera und lassen Sie Face++ eine KI-basierte Gesichtserkennung durchführen. Für jedes erkannte Gesicht wird ein Flow ausgelöst. Homey versucht automatisch, die Gesichter mit einer Reihe bekannter Gesichter abzugleichen, die Sie selbst hochladen können. Die App schätzt außerdem Geschlecht, Alter, Emotion und ob die Person eine (Sonnen-)Brille oder eine Maske trägt.

Anwendungsfälle: Anwesenheitserkennung, Sicherheit, Gesichtsbasierte Zugangskontrolle, Spaß
